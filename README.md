# Система бронирования (отели и билеты)

**Автор:** Кончевич Мирослав Валерьевич
**Группа:** 453501

## О проекте

Курсовой проект по дисциплине «Модели данных и системы управления базами данных».

Предметная область — платформа бронирования отелей и билетов на транспорт (авиа/жд/автобус): поиск и бронирование номеров в отелях, поиск и покупка билетов на рейсы, управление пользователями и ролями, история бронирований, отзывы и журналирование действий.

**СУБД:** MySQL
