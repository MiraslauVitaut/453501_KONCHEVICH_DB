О проекте

Курсовой проект по дисциплине «Модели данных и системы управления базами данных».

Предметная область — платформа бронирования отелей и билетов на транспорт (авиа/жд/автобус): поиск и бронирование номеров в отелях, поиск и покупка билетов на рейсы, управление пользователями и ролями, история бронирований, отзывы и журналирование действий.

Выбранная СУБД:MySQL

Структура репозитория

- `docs/lab1/functional_requirements.md` — функциональные требования (Лабораторная работа №1)
- `docs/lab1/entities.md` — список и описание сущностей БД (Лабораторная работа №1)
- `docs/lab1/er_diagram.png` — ненормализованная инфологическая схема БД (Лабораторная работа №1)

Схема репозитория будет дополняться по мере выполнения следующих лабораторных работ (даталогическая модель, нормализация, физическая модель, SQL-запросы, триггеры и процедуры, итоговое приложение).
